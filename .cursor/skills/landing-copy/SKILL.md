# Landing copy (klaut)

Apply when writing marketing or waitlist copy for klaut.pro.

- English primary. Direct claims. No em/en dashes. No stock "X, not Y" antithesis.
- Plain language: short words, one idea per sentence.
- Hero: wordmark first, one headline, one lede, one CTA (waitlist). No stats or cards in the first viewport.
- Positioning: MCP control plane for agent tools (Secrets, Mail, Search, Database, Storage, Literature, Writing) with unified token billing. No Books.
- Tone: clear and concrete. Prefer commas, periods, parentheses.

Tokens and motion live in `app/globals.css`.
